# WorldGuessr local build

This is a cleaned, static-hosting copy of the permitted WorldGuessr game page.

- Static game assets, fonts, images, and music are included locally.
- The third-party ad SDK and rotating promotional system were removed.
- The small static menu uses UTM parameters and can be toggled with Ctrl+Shift+Y.
- Street View, the game API, multiplayer WebSocket, and country flags remain live services because they cannot be replaced by static files without changing the game’s backend.

All files are kept below GitHub’s 20 MB per-file limit.
